# #43 设置中心，第一轮评估

## 结论

- **总分：6.4 / 10，不通过**
- 已验证：设置 JSON 的缺失、未知字段、非法值和原子读写单元测试；Go 静态检查、完整测试和前端类型构建均通过。

## 得分点

- 设备级设置有版本字段、范围校验和原子替换写入。
- Dashboard 默认扫描窗口与 inactive 上限已从设置读取；设置页有明确入口、分类与保存错误反馈。
- 项目管理从 Dashboard 顶栏迁入设置页，卡片快捷操作保留。

## 失分点

- 注意力、专注、时间估算和每日引导设置尚未驱动对应运行逻辑，保存后没有实际效果。
- Dashboard 未读取保存后的窗口、刷新和每日引导值，设置与界面状态不一致。
- 设置页只支持移除项目，未承接项目根添加及主线/两个支线槽位调整；单项恢复默认与即时保存也未实现。
- `daily_boot_enabled` 无法区分旧文件缺字段与用户显式关闭，兼容合并会改变默认。

## 待规划问题

- 让运行参数通过 settings 读取，包含专注延长、提醒保护期、时间估算与每日引导。
- 补全设置页项目根、槽位和即时保存/单项恢复默认交互。
- 以指针或版本迁移区分缺失布尔字段与显式 false。
