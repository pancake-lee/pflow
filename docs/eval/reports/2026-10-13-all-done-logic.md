### #56 跨项目短间隔切回导致焦点时间重复归属

- **严重程度**：P1；来源 #42。
- **现象与影响**：A 09:00–09:20，B 09:20–09:23，A 09:23–09:40，A 应为 37 分钟却得到 40 分钟，B 同时得到 3 分钟。按项目独立合并忽略中途其他项目活动，影响时间展示与建议依据。
- **证据**：[focus.go:181](../../../internal/timetrack/focus.go#L181)，隔离 Go 复现。

### #57 关闭每日引导后刷新页面无法进入 Dashboard

- **严重程度**：P1；来源 #43。
- **现象与影响**：daily_boot_enabled=false 分支提前 return，bootChecked 永远保持 false；App 的 Dashboard 分支无法显示，停在空白加载层。
- **证据**：[App.vue:30](../../../web/src/App.vue#L30)，执行提取并转译的真实 onMounted 回调，dashboard_renders=false。

### #58 缺字段设置读取改变默认行为

- **严重程度**：P2；来源 #43。
- **现象与影响**：读取 {version:1,dashboard:{window:"7d"}} 时，缺失的 refresh_seconds、daily_boot_enabled、max_inactive 被视为显式零值，得到 0/false/0，默认应为 30/true/1。首次兼容合并不符合默认保留承诺。
- **证据**：[settings.go:95](../../../internal/settings/settings.go#L95)，隔离临时 JSON 复现。

### #59 浏览器筛选覆盖设置中心已保存的运行偏好

- **严重程度**：P2；来源 #43。
- **现象与影响**：Dashboard 挂载时先读服务设置、随后用已有 localStorage 覆盖扫描窗口、数量和刷新间隔；保存设置触发重新挂载也沿用该顺序，有旧筛选的浏览器继续使用旧值。
- **证据**：[DashboardView.vue:754](../../../web/src/views/DashboardView.vue#L754)，源码数据流核对，未浏览器实测。

### #60 Codex 过程回复被误判为空闲

- **严重程度**：P1；来源 #26。
- **现象与影响**：task_started 后只有 assistant phase=commentary 过程回复、尚无完成事件时，扫描状态变为 idle。误判会改变用户对执行状态和注意力的判断。
- **证据**：[activity.go:247](../../../internal/codex/activity.go#L247)，校正夹具 mtime 后隔离扫描得到 idle，预期 busy。
