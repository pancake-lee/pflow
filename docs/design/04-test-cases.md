# 提醒分数算法 — 双维度测试用例设计

> 基于双维度算法文档 `reminder_score_algorithm.md` 设计。
> 常量同前：`ProtectMin=5`, `WWait=1.0`, `WStreak=0.5`, `PrimaryBonus=2.0`, `WCorrect=0.5`, `ExpPower=2.0`, `MinFactor=0.5`, `FogProtectMax=0.9`, `FogProtectMin=0.5`, `FogBaseNonProtect=0.3`, `NoCurrentOtherFog=0.7`。
> 阈值：低提醒 `<2`，中提醒 `2-5`，高提醒 `5-10`，超高提醒 `≥10`。
>
> **测试容差**：`TOLERANCE = 5`（绝对值），定义在 `score_test.go` 顶部，可手动调整。

---

## 0. 0-100 标度换算

算法原始输出值范围差异大（`reminder_score` 0~∞，`fog_score` 0~1），不便于人类阅读和前端使用。因此增加一层换算，输出 0-100 的整数值：

| 输出字段                       | 范围 | 换算公式                                               |
| ------------------------------ | :---: | ------------------------------------------------------ |
| **Highlight**（高亮值）  | 0-100 | `min(100, round(log₁₀(reminder_score + 1) × 25))` |
| **FogPct**（迷雾百分比） | 0-100 | `round(fog_score × 100)`                            |

- `Highlight = 0` → 无高亮效果；`100` → 最强高亮（脉冲+发光+饱和度）。
- `FogPct = 0` → 完全清晰；`100` → 完全被迷雾覆盖（灰度+模糊+半透明黑）。
- 当前项目永远 `(0, 0)`。

> 换算常量为 `HighlightLogScale = 25.0`，定义在 `config.go`。调整该值可改变映射曲线的陡峭程度（越大越陡）。

以下每个用例的输出表同时列出原始值（`Score`/`Fog`）和 0-100 标度值（`HL`/`Fog%`）。

## 用例 1：主线专注 1h → 支线 waiting 30min 被提醒（无 focus）

**场景**：用户持续工作主线 1 小时，支线已等待 30 分钟。
**前置**：`cur=P`, `focusActive=false`, `streak_cur=60`

| 输入      | waiting | streak | total | last_active | is_primary |
| --------- | :-----: | :----: | :---: | ----------- | :--------: |
| P (主线)  |    0    |   60   |  60  | 1min 前     |     ✓     |
| S1 (支线) |   30   |   0   |  20  | 5min 前     |     ✗     |

**计算**：

- P: `base=0`, `factor=0` (is_cur) → `adjusted=0` → `reminder=0`
- S1: `base=30`, `streak_ratio=min(60/5*0.5,2)=2`, `factor=2` → `adjusted=60` → `reminder=60²=3600` (超高)
- `maxRem=3600`, S1: `fog = 0.3 * (1 - min(1, 3600/3600)) = 0`
- P: `fog = 0` (is_cur)

| 项目 |          Score |      HL      |     Fog     |    Fog%    | 视觉意图                             |
| ---- | -------------: | :----------: | :---------: | :---------: | ------------------------------------ |
| P    |              0 |      0      |      0      |      0      | 正在做，无特效                       |
| S1   | **3600** | **89** | **0** | **0** | 清晰且**强烈高亮** — 引导切换 |

## 用例 7：今日累计校正—支线远超主线

**场景**：整天在支线上（60+40），主线仅 10。
**前置**：`cur=S1`, `focusActive=false`, `streak_cur=20`

| 输入      | waiting | streak | total | last_active | is_primary |
| --------- | :-----: | :----: | :---: | ----------- | :--------: |
| P (主线)  |    5    |   0   |  10  | 2min 前     |     ✓     |
| S1 (支线) |    0    |   20   |  60  | 1min 前     |     ✗     |
| S2 (支线) |    3    |   0   |  40  | 3min 前     |     ✗     |

**计算**：

- 支线总和中位数 = (40,60) → median=50
- P: `base=5`, `streak_ratio=2` (当前是支线? cur=S1 是支线, P是主线 → bonus=4), `factor=4` → `adjusted=20`, 校正 `correction = (50-10)*0.5=20`, `adjusted_final=40` → `reminder=1600`
- S1: is_cur → `reminder=0`
- S2: `base=3`, `streak_ratio=2` (非当前, 当前是支线但目标也是支线→无bonus), `factor=2` → `adjusted=6` → `reminder=36`
- `maxRem=1600`, 迷雾：
  - P: `fog = 0.3*(1 - min(1,1600/1600)) = 0`
  - S2: `fog = 0.3*(1 - min(1,36/1600)) = 0.3*(1-0.0225)=0.293`
  - S1: fog=0

| 项目 |          Score |      HL      |       Fog       |     Fog%     | 视觉意图                    |
| ---- | -------------: | :----------: | :-------------: | :----------: | --------------------------- |
| P    | **1600** | **80** |   **0**   | **0** | 清晰+高亮 — 主线被忽视太久 |
| S1   |              0 |      0      |        0        |      0      | 清晰（当前）                |
| S2   |             36 | **39** | **0.293** | **29** | 轻度迷雾 + 微亮（分数仍高） |
