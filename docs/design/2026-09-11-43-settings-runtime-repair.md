# #43 设置中心运行时接入修复

> 本文档是 [#43 设置中心](../backlog.md#43-设置中心与项目管理迁入) 首轮评估后的修复方案。

## 目标

使每项已展示设置立即影响对应体验，并让设置页成为项目策略的完整管理入口。

## 方案

- 设置读取 API 保持默认合并，使用原始 JSON 的字段存在性处理旧版本布尔值，避免缺失字段改变默认。
- Dashboard 初始加载设置后以其值初始化扫描范围、刷新周期和每日引导；保存成功后即时刷新。
- 专注延长、保护期、时间估算从运行时设置读取，不再只使用编译期常量。
- 项目管理展示可见项目，提供设为主线、两个支线、普通和移除操作；Dashboard 卡片快捷操作仍复用原 API。
- 表单控件变更后立即保存，分类恢复默认保留，同时补充单项恢复默认。

## 验收

- 修改每项设置后无需重启，Dashboard 或下一次对应操作立即体现结果。
- 重启服务、缺失旧文件、非法输入和保存失败均有稳定行为。
- 项目根与三个槽位在设置页可完整管理，且与 Dashboard 一致。
