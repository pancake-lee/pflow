## 时间追踪

### #42 基于 tmux 焦点事件的项目计时

- **状态**：Done
- **历史逻辑评估**：5.0（逻辑轮，不通过；正确性 4.0 健壮性 6.0 完整性 5.0），详见 [2026-10-13 Done 任务逻辑评估](../eval/reports/2026-10-13-all-done-logic.md)。
- **历史评估**：8.6（上一轮总览记录）。
- **分组**：时间追踪
- **背景**：现有活跃时间把 tmux attach、会话切换和 detach 当作焦点事件。用户切到编辑器、浏览器或其他应用时不会产生失焦记录，项目时间会被持续累计，不能代表实际窗口焦点。
- **分析**：当前环境已安装 tmux 3.7c，具备 `client-focus-in` 与 `client-focus-out` hooks。tmux 3.2a 不支持这些 hooks，无法提供本任务所需的准确事件。`focus-events` 必须持续启用，且用户终端需支持焦点报告；不具备事件能力时，项目时间应继续走既有消息估算链路。
- **方案**：`pflow serve` 保守合并 tmux 配置并同步运行时开关，只补充缺失的焦点事件设置，不覆盖用户其他配置或重复添加相同设置。服务注册新版 client focus hooks，将事件记录关联到 pflow 托管会话。项目时间聚合按跨项目切换立即截断，同项目在 5 分钟宽限期内恢复焦点时合并为同一连续时段；宽限期作为代码常量。无有效焦点数据时维持消息估算降级。
- **任务列表**：
  - [x] 42.1 实现 tmux 配置的保守检查、补充与运行时启用，并为已启用、缺失、显式关闭和包含其他用户配置的情况补充测试。
  - [x] 42.2 将焦点记录替换为 client focus 事件，识别不支持的 tmux 版本并保留可诊断的消息估算降级。
  - [x] 42.3 实现含 5 分钟同项目恢复宽限期的项目时间聚合，覆盖跨项目切换、同项目恢复、超时恢复、未闭合事件和异常事件序列。
  - [x] 42.4 接入 Dashboard、`pflow suggest` 和提醒评分，更新时间追踪说明并完成自动验证。
- **验收**：
  - [x] `pflow serve` 不改写已有 tmux 配置，只在缺失时补充一次 `focus-events on`，运行中 tmux 同步开启。
  - [x] 项目 A 切换至项目 B 时，A 在失焦时刻停止累计，B 从获焦时刻开始累计。
  - [x] 项目 A 失焦后 5 分钟内未切至其他项目且重新获得焦点，间隔合并进 A；超过 5 分钟不合并。
- [x] 无新版 hook、无焦点日志或日志无匹配项目时，Dashboard、行动建议和 CLI 均回退消息估算且不影响其他会话。
- **评估**：8.5（2026-10-13 完整复评；正确性 9.0 健壮性 8.5 可维护性 8.5 简洁性 8.5 一致性 9.0 惊喜度 7.0 可用性 9.0 交互体验 8.5），Done。
- **本轮自动验证**：focus hook、配置保守合并、跨项目切回、同项目宽限、午夜及异常序列回归通过；计时被 API/attention 共用，Go 全量竞态检查通过。
- **复评结论**：跨项目立即截断，同项目保留 5 分钟宽限；真实终端是否发送焦点事件沿用既有环境与用户验收，不反向复核。

### #51 提示分与遮挡分诊断日志收敛

- **状态**：Done
- **历史逻辑评估**：9.0（逻辑轮，通过；正确性 9.0 健壮性 9.0 完整性 9.0），详见 [2026-10-13 Done 任务逻辑评估](../eval/reports/2026-10-13-all-done-logic.md)。
- **历史评估**：8.5（上一轮总览记录）。
- **分组**：可观测性
- **背景**：Dashboard 的周期刷新会对每个项目和会话以 Info 级别重复记录提示分、遮挡分计算输入。2026-09-15 日志在约一小时内累计 7,407 行、约 1.06 MB，其中该计算明细占 3,496 行；常规运行日志被诊断噪声淹没。
- **分析**：这些逐项目、逐会话明细只服务于评分排查，不是日常运行事件。当前日志初始化固定允许 Debug 级别，单纯把调用改为 Debug 也不能令默认运行静默；需要将“是否输出完整注意力计算链路”作为服务启动时显式开启的诊断能力。
- **方案**：默认不输出提示分与遮挡分的逐项计算日志，保留启动、状态变化、失败等常规可观测事件。为 `serve` 提供专用注意力诊断开关，开启时才输出完整计算输入，便于下次复现和追踪，且不改变评分结果或 Dashboard API 契约。

  - [x] 51.2 将逐项目、逐会话的评分计算日志限定在该开关开启时，默认请求不再产生这些明细。
  - [x] 51.3 补充关闭与开启两种路径的回归测试，完成 Go 格式化、静态检查和测试。
