# 归档

这里保存已经完成周期、一次性审查、版本记录、旧版参考笔记和历史产物。归档材料用于追溯，不作为当前实现或流程的规范。

- `cycles/`：按开发周期整理的实现记录
- `reviews/`：阶段性代码质量审查
- `legacy/`：已由 Harness 手册吸收的旧参考文档
- `output/`：历史命令输出和截图
