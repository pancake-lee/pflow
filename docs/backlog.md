## 产品定位决策

**从**：多 Agent 会话的状态查看工具
**到**：多 Agent 会话的注意力管理与调度工具，让用户能快速判断下一步该关注哪一路 Agent。

核心 workflow：启动 Agent → 自动发现会话 → 按项目归类 → Dashboard 汇总状态 → 用户依据提醒和建议进行关注、授权或切换。

**主动不做的事**：

- 不替代 Claude Code、Hermes 或其他 Agent 的对话和执行能力。
- 不自动替用户批准高风险操作。
- 不在 Dashboard 中复制完整的 Agent 工作界面。

## 拒绝清单

- 以独立项目 ID/名称实体替代“路径即项目”模型。
- 通过抓取终端渲染内容承载所有 Agent 状态，优先使用稳定的 JSON 或明确命令输出。
- 在 pflow 内自建 WebSocket + PTY 桥接，优先复用成熟的 ttyd + tmux 链路。
